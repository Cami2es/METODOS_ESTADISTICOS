# METODOS_ESTADISTICOS
CURSO ESTADISTICO 3EER SEMESTRE AGOSTO-DICIEMBRE 2026


## Presentación

Este repositorio contiene las actividades, tareas, prácticas de laboratorio y scripts desarrollados durante el curso de Métodos Estadísticos, correspondiente al tercer semestre de Ingeniería Forestal.

## Objetivo del repositorio

Organizar y conservar los trabajos realizados durante el curso, así como mostrar el uso de herramientas estadísticas para el análisis e interpretación de datos.

## Organización del repositorio

- **Scripts:** contiene los códigos y ejercicios realizados en R.
- **Tareas:** contiene los documentos PDF de las tareas del curso.
- **Laboratorios:** contiene los reportes y prácticas de laboratorio en PDF.

## Actividades del curso en orden cronológico

En este apartado se irán agregando las actividades realizadas durante el semestre, ordenadas por fecha y acompañadas de una breve descripción.
